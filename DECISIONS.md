## Decision record checklist

- [ ] Named accountable decision maker and approval authority.
- [ ] Exact scope/contract change and affected requirements/tickets.
- [ ] Options, measured evidence, constraints, cost and operational consequences.
- [ ] Security/privacy/data/provider/staffing impact and migration/rollback where applicable.
- [ ] Chosen option and explicitly deferred items.
- [ ] Dated approval with reviewer and evidence/reference.
- [ ] Update source traceability, module/ticket scope and maintained app guides in the same implementation change.

A default or a capability demonstrated locally is not a signed production architecture exception. If a decision changes contracted scope, record that change rather than quietly closing the affected Must requirement.
